## 1. 数据质量与结构

### 1.1 基本分布

- 跨境卖家可售：42 行；仅限本土销售：8 行。
- 清洁剂：10 行，是表中最大类群。
- 其余大量行属于食品、保健品、美妆、香水、SIM 卡、电气或促销泛词。
- `商品总数` 有 17 行缺失。
- 每行都有 10 张相关商品图，但没有对应商品 ID/链接，不能将图片安全映射为具体 Ozon 商品记录。

### 1.2 关键局限

表中缺少：

- Ozon productId / SKU / 商品页 URL；
- 单品标题、品牌、卖家与实际售价；
- 单品销量、评论数与上架时长；
- 实际单品重量和包裹尺寸；
- 采购价、MOQ、库存和发货时效；
- 品牌授权、认证和图片使用权。

因此不能从本表得出“某商品利润可观”或“没有合规风险”。

### 1.3 指标使用边界

- 销量/销售额/转化率作为 Seerfar 估算与聚合信号，不是 Ozon 财务真值。
- `市场空间`、`商品可见度` 等指标在未核对 Seerfar 官方定义前，不纳入硬阈值。
- 表内重量/体积是关键词关联商品的聚合口径，可能含异常大件，不能替代单品包裹数据。

## 2. 专业卖家初筛顺序

### 第一层：经营可行性硬过滤

1. 删除仅限本土销售。
2. 删除食品、保健品、药品、种子、美妆、香水、电气、SIM 卡等当前不进入的类目。
3. 删除液体、膏体、粉末、大件、易碎、品牌/IP 明显风险商品。
4. 删除纯促销、积分、低价和宽泛购物词，不让平台活动流量冒充具体商品需求。

### 第二层：需求质量

对剩余行检查：

- 月搜热度与增长是否支持真实需求；
- 加购率与转化率是否同时健康；
- 转化集中度是否过高；
- 销量是否分散在足够多商品/卖家中；
- 退货取消率是否较低；
- 增长是否可能由促销脉冲驱动。

建议的**研究起点而非永久阈值**：价格约 800–3000₽、转化率 ≥1.5%、退货取消率尽量 ≤8%、转化集中度尽量 ≤25%。这些值需要真实复盘校准，不能让 LLM 自行修改。

### 第三层：商品级补全

对通过方向的 10 张相关图必须补全商品身份：

- 在 Seerfar 商品详情/商品级导出中获取 productId 与商品链接；
- 记录每个图片对应的商品，不再只挂关键词；
- 读取单品价格、品牌、评论、销量、实际上架时长与类目；
- 按 productId 去重并检查是否已进入现有 pipeline。

### 第四层：1688 与经济硬闸

- 使用已确认的商品图进行 1688 图搜；
- 同一性闸 + top3–5 人工选源；
- 获取真实采购价、MOQ、国内运费、尺寸重量与发货时效；
- 运行 `pricing.calc`，含佣金、物流、汇率、推广准备金和风险参数；
- 经济通过后才生成媒体，最后进入原图审。

## 4. 推荐的自动化输入契约

Seerfar 导入后，不应让 LLM 直接自由判断。每行先生成结构化候选：

```text
source_row / keyword / category / export_date / metrics
specific_intent=true|false
cross_border=true|false
category_risk=pass|review|reject
data_quality=pass|missing_fields
```

LLM 只输出：

```text
priority / rationale / evidence_fields / risks / missing_data
```

规则代码负责硬过滤，LLM 负责剩余候选的排序与解释，用户只批准方向和短名单。

## 5. 对当前流程的具体调整

```text
Seerfar 关键词表导入
  → 数据质量检查与泛词/类目过滤
  → LLM 排序与解释
  → 用户确认方向
  → 获取商品级 Seerfar 明细（必要新增步骤）
  → 商品去重与合规检查
  → 已确认商品图进入 1688 图搜
  → 同一性 + 人工选源
  → 经济/趋势硬闸
  → 生图与图审
```

**不能把当前 CSV 的 500 张图直接批量送入 1688**：这会把泛词、重复商品、品牌品和不合规品同时放大为 VL 与找货成本。

## 6. 下一次 Seerfar 导出建议

优先导出商品级数据，并在导出前缩小范围：

- 跨境可售、非限制类目；
- 具体商品/场景需求词，而非促销泛词；
- 价格带约 800–3000₽；
- 有稳定销量与评价，但不是高度头部垄断；
- 小件、非液体、非易碎、非电气、非食品；
- 包含 productId/URL、标题、品牌、图片、价格、销量、评论、类目和统计窗口。

这样才能形成“表中商品 → 图片 → 1688 货源 → 经济快照 → 自动上架”的完整证据链。

## 2. 现状评审：两张 slot1 成品（亲眼目检）

### 卡1 皂液器（自动感应出泡）
- 画面：产品静立于浴室台面，标题"Без сверления — за 3 секунды"，芯片 免打孔/3秒/无痕。
- **买家视角**：静物。感应皂液器的"魔法时刻"是**手伸过去泡沫自动落掌心**——封面上没有手、没有泡沫、没有使用动作，情绪价值为零。卖点全靠文字芯片承载。
- **内容缺陷**：标题与芯片①重复（"Без сверления"出现两次，浪费一条信息位）。

### 卡2 抽屉餐具收纳
- 画面：空收纳盒立于桌面，标题"Влезает в любой ящик"，芯片 8格/免打孔/32–45cm。
- **买家视角**：**空盒 + 竖立角度 → 看不出是抽屉用品，更感受不到"抽屉从乱到齐"的爽点**。收纳品类的情绪=秩序感，必须让抽屉和餐具在场。
- **内容缺陷**："Без сверления"对抽屉收纳是无意义卖点（没人要在抽屉里打孔），占了一条芯片位；32–45cm/8格仍是 need_confirm 编造数（待人工核）。

### 运营视角诊断（根因）
v3 重构的主题是**合规攻坚**（禁字/禁品牌/禁信息图海报化），留白网格+文字双轨+静物英雄照全部达标；但 slot1 提示词明确写着 "standing on a clean surface"——**情绪/使用维度被整体推迟到 slot4（使用）/slot5（场景），封面只剩"产品+卖点文字"**。这在漏斗里少了一层：买家在搜索页决定点不点时，看到的不是"用了之后的爽"，而是"一个物体+三条参数"。

## 3. 第一性原理：搜索页封面的三个任务

买家在搜索结果网格里给每张缩略图 ≈0.3 秒：
1. **识别**——0.1 秒内认出"这是什么品类"（静物照其实够用）；
2. **区分**——和上下左右邻居不一样（家居类目邻居多为白底静物+信息图，暖调使用中场景天然区分）；
3. **许诺**——看到"用了之后的画面"（泡沫落掌心/整齐的抽屉），而不是"一个东西"。

v3 满足了 1，部分满足 2（暖场景已是差异化），**完全没做 3**。

## 4. slot1 v4 方案（草案）

### 4.1 核心变更
- slot1 从"静物英雄照"改为 **"兑现时刻"（payoff moment）**：产品正在交付核心价值的那一瞬间。
  - 皂液器：a hand under the nozzle catching rich white foam（手的风险见 4.3 兜底）
  - 抽屉收纳：the organizer inside a half-open kitchen drawer, compartments filled with forks spoons and knives
- **不变量全部保留**：pixel-identical 产品、顶部 25%/左中带/左下留白（动作安排在画面右下 2/3，与留白区不冲突）、禁字禁包装禁 logo、photographer 人格、prompt_extend=False、negative_prompt。
- 与 slot4 的分工：slot1=兑现瞬间特写（情绪钩子），slot4=使用过程+尺度感（剧本）。避免雷同的机械保证：content_agent 生成时 slot1.cover_action ≠ slot4.action。

### 4.2 content_agent 配套
- spec slot1 新增字段 `cover_action_en`（英文动作描述，从商品核心卖点推导）——当前 slot1 只有 scene+copy，无动作源；
- **芯片与标题去重**机械校验：copy_icons 不得与 copy_title 有重叠词（卡1 事故）；
- **卖点相关性**：BANNED 清单外，加一条 prompt 约束"卖点必须对该品类有意义"（卡2"免打孔"事故）；LLM 难机械校验，先入 need_confirm 人工兜底。

### 4.3 手部畸形兜底（已知 AI 通病，slot4 注释已有此模式）
VL 闸加一条检查：含手的 slot1 → 手部畸形 → 自动降级为无手变体（泡沫悬空喷出 / 抽屉特写无手）重试一次 → 仍失败回退 v3 静物版（不阻塞出图）。

### 4.4 A/B 闭环（接 eval 体系）
每张卡生成**两个 slot1 变体**（A=v3 静物 / B=v4 兑现时刻），成本 +$0.033/卡；上架后用官方 A/B-тест фото（或第三方 API 工具）跑 CTR，结果落 reviews 表 kind="ab_cover"——把"封面该不该有情绪"变成可回归的数据资产，而不是一次性口味之争。

## 5. 决策点（待用户拍板）

1. **slot1 v4 方向**：静物 → 兑现时刻，是否做？（建议：做，但 A/B 双跑而非直接替换）
2. **适用范围**：先只对 2 张待审卡重做 slot1 验证视觉，还是直接进 content_agent+image_worker 改模板？
3. **A/B 测试通道**：官方后台手动（299₽/卡量级，先确认现价）vs 第三方 API 工具（sellium 类，可自动化）——V1 建议官方手动，量小。
4. 手部风险接受度：接受"含手优先 + 无手降级 + 静物兜底"三级，还是直接无手（牺牲部分情绪，换成功率）？

## 7. 实战测试记录（2026-11-11，6 张图 $0.198）

对 2 张待审卡各跑 3 轮 slot1 v4（参考图=slot2 白底图，输出至 `data/gen/<offer>-ab/`，A 版资产未动）：

| 轮次 | 结果 | 教训 |
|---|---|---|
| R1 | 卡1 兑现时刻成功但**手落左中带撞 PIL 芯片**；卡2 **同一性失守**（浅灰 8 格→深灰多格+多一副托盘） | 动作必须限定画幅区域；动作描述必须自带同一性关键词（exact light-grey color / exact compartment layout） |
| R2 | 模板加"动作限右半幅"后：卡1 模型**自加人脸**占左上（违反顶部净空）；卡2 同一性修好但 **no hands 被无视**（拿刀的手） | VL 闸只查文字查不出人脸；**人体部位负面约束不可靠**（2/2 次被无视） |
| R3 | 模板加"只允许动作要求的那只手、从右/下边缘入画、禁人脸"：**卡1 通过**（手+泡沫兑现瞬间、芯片区干净、顶部净空）；卡2 仍有手（持勺）+ 抽屉底部出现纸箱杂物 | 卡1 B3 = 可上架 B 版；卡2 B3 = 可用但有备注（手其实不减分，纸箱需图审判定） |
| R4 | 用户目检发现卡1 B3 **手臂从右侧穿过机身**（物理不可能）→ 模板改"手仅在前景、禁与产品交叠/穿越、从底部或左前入画"；结果：左前入画撞芯片区 + 左下出现一本书 | 入画方向必须与留白区分工兼容：右进穿模、左进撞芯片——正解是**仅从底部入画** |
| R5 | 模板锁定"仅从底部边缘入画"：**卡1 B5 全项通过**（单手底部托起接泡、芯片区干净、无杂物、产品零形变） | **卡1 B5 = 正式 B 版**；手部约束最终形态：至多一只手、仅从底部入画、全程前景、禁穿越、禁人脸禁其他部位 |

## 8. 跨品类压测（2026-11-11 狗玩具，4 张图 $0.132）

品类：宠物用品（抛出寻回飞盘，offer 897690954714，¥5.3/销量1万）——情绪最浓品类 + 动物解剖 + 全动态场景，对模板最大压力。

| 轮次 | 结果 | 教训 |
|---|---|---|
| A(v3) | 静物技术满分，情绪为零（玩具躺草地） | v3→v4 差距的干净对照组 |
| B-R1 | 兑现时刻成立（金毛叼玩具奔向主人），但 **x≈30% 生硬垂直接缝**（左侧被画成平板米色面板） | 刚性几何留白（x8-42% 色带）与"连续照片"在全动态场景互斥，模型用平板造假 |
| B-R2 | 接缝更硬 + 顶部被树冠占满标题不可读 | 同上，且暴露**字色写死深灰**的架构缺陷 |
| B-R3 | **全项通过**：接缝消失、浅天空+深字可读、狗解剖自然、玩具零形变 | 两条架构级修复生效（见下） |

**两条架构级修复（本轮产出）**：
1. **几何留白 → 景深留白**（模板）：不规定色带坐标，要求背景整体浅景深虚化、顶部和左侧尤其干净——虚化本身就是贴字位；保留的硬约束只剩"动作右半幅 + 左下角空"（平台角标区）。
2. **字色写死 → PIL 自适应** [user-decided 2026-11-11]：text_overlay.overlay_title 按标题区平均亮度选色（>140 深字 / 否则浅字），背景深浅不再强求。text_overlay selftest + 13 pytest 全绿。

**手部约束最终形态**（经皂液器 6 轮 + 狗玩具 3 轮收敛）：至多一只手、仅从底部入画、腕连小臂不断腕、全程前景不穿越产品、禁人脸禁其他部位；`no hands` 负面约束服从率低，含手动作不如纳入规则精确管控。

- 不动 slot2-8 模板（它们各有漏斗职能且已过合规攻坚；slot4/5 本就是情绪位）；
- 不恢复 style_ref 机制（禁字攻坚结论不变）；
- 不改文字双轨制任何部分。

# Ozon 佣金档位计算规则（跨境中国卖家）

> 调研日期：2026-11-11。结论用于 `pricing.py` 佣金档迭代与审核台定价计算器 UI。

## 1. 规则：类目 × 价格档，两个维度

- **费率由类目决定**：每个叶子类目（description_category_id）有自己的费率，
  同类目内按售价再分档。本地库 `data/ozon-commission.json`（542 类目 × 3 档，
  源自毛子ERP `api.config/get_ozon_cate_commission`）即此模型。
- **价格档边界全类目统一**：2026-07-01 起 Ozon 把价格段从六档缩为三档。
  毛子ERP 口径（跨境）：`≤1500₽ / 1500–5000₽ / >5000₽`。
  来源：本地库 `_meta.tier_meaning` + greenmp.ru「1 июля: Ценовые сегменты
  сократили с шести до трёх」（https://greenmp.ru/blog/komissii-ozon/）。
- **佣金按下单时折后实际售价计算**（促销降价可把商品打入更低档）。
  来源：marketbridge.cloud「диапазон берётся по цене продажи на момент заказа」
  （https://marketbridge.cloud/ru-RU/knowledge/komissii-ozon-global/）。

## 2. 注意：两套口径不要混

| 口径 | 适用 | 费率量级 |
|---|---|---|
| 毛子ERP 三档（本项目采用） | 跨境中国卖家工具 | 家居 12/14/18% |
| Ozon 本土「统一费率」 | 俄本土 FBO/FBS（2026-04 起佣金+物流+处理合并） | 家居花园 52% |

seller-edu.ozon.ru 官方表本次被反爬（fab_chlg 挑战）未直接核验；
本土 52% 是**合并物流的统一费率**，与跨境 12% 纯佣金不可直接对比。
FBP 与 rFBS 费率不同（FBP 通常低约 1 个百分点），本项目走 rFBS。

## 3. 实现落点

- `pricing.calc`：低档起算 → ₽售价跨档则换档重算至收敛（最多 3 次）；
  `commission_tier` 参数可人工锁档。
- 审核台编辑器「佣金档」下拉：按当前 spec 类目实时渲染
  `档1 ≤1500₽ · 12% / 档2 ≤5000₽ · 14% / 档3 >5000₽ · 18%`（示例为家居用品），
  默认「自动（按折后售价选档）」。
- 类目不在佣金库 → `commission_tiers` 抛 KeyError，界面显示「自动（类目不在佣金库）」，
  需人工处理（TODO：类目选择器）。
